# Terre Anadolu Şarküteri

Terre Anadolu Şarküteri için hızlı, erişilebilir ve tamamen statik tanıtım sitesi.

## Yerelde çalıştırma

Herhangi bir derleme adımı yoktur. Proje klasöründe basit bir HTTP sunucusu açın:

```bash
python3 -m http.server 8080
```

Ardından `http://localhost:8080` adresini açın.

## Yayınlama

Dosyalar GitHub Pages, Cloudflare Pages, Netlify veya benzeri herhangi bir statik barındırma hizmetinde doğrudan yayınlanabilir.

## İçerik

- `index.html`: Sayfa içeriği ve SEO metadatası
- `styles.css`: Görsel sistem ve responsive düzen
- `script.js`: Mobil menü ve kaydırma animasyonları
- `assets/`: Logo ve hero görseli
- `catalog.json`: Arama sistemleri ve agent'lar için makine tarafından okunabilir ürün kataloğu
- `llms.txt`: AI sistemleri için kısa işletme özeti, resmi kaynaklar ve aksiyon bağlantıları

## Analiz çerezleri

Google Analytics (`G-CGFZ4H8YH2`) yalnızca ziyaretçi "Kabul et" seçeneğini seçtikten sonra yüklenir. Tercih tarayıcının yerel depolamasında saklanır; depolama kullanılamıyorsa sonraki ziyarette yeniden sorulur. Ziyaretçiler sayfanın altındaki "Çerez tercihleri" düğmesiyle kararını değiştirebilir. Onayı geri çekmek, Analytics çerezlerini temizler ve açık sayfayı yeniden yükleyerek izlemeyi durdurur.
